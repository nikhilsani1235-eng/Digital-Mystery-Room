# Digital-Mystery-Room
Digital Mystery Room 

Digital Mystery Room is an interactive web-based mystery game where players explore clues, solve puzzles, and use their logical thinking to uncover hidden secrets. Built using modern web technologies, the project provides an engaging and immersive gaming experience.

Features

- Interactive mystery-solving gameplay
- Clue discovery and puzzle-solving challenges
- User-friendly interface
- Responsive web design
- Built with modern JavaScript and TypeScript technologies

Technologies Used

- React
- TypeScript
- Vite
- HTML
- CSS

Getting Started

1. Clone the repository.
2. Install the dependencies using "npm install".
3. Start the development server using "npm run dev".

Purpose

This project demonstrates web development skills, interactive UI design, and problem-solving through an engaging digital mystery game.
